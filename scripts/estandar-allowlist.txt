#
#   [externos]  comandos de otros marketplaces que este repo referencia con
#               legitimidad. Mantener la lista al día ES el chequeo: cuando
#               upstream renombra o retira uno, el redirect muere en silencio
#               y esta línea es el único lugar donde queda registrado.
#
#   [retirados] comandos que existieron acá y se retiraron. Mencionarlos es
#               legítimo SOLO en un acta —`docs/**`, `CHANGELOG.md`,
#               `DEFUNCIONES.md`— o dentro de una región `<!-- acta -->`.
#               En un archivo vivo (`commands/`, `agents/`, `README.md`) un
#               comando retirado sigue siendo sediment.
#
#   [paths]     rutas que un archivo nombra con razón aunque no existan en
#               este repo: viven en el repo consumidor, no acá.
#
# Formato: un ítem por línea, `#` inicia comentario. Los comandos van sin la
# barra inicial y sin namespace (`prd-pipeline`, no `/host-orchestrator:prd-pipeline`).
